# NucleusX-Scrapping
It scrap's Resident data from NucleusX and store into .xlxs file.

⬇️⬇️⬇️⬇️⬇️⬇️⬇️⬇️⬇️⬇️
✅First run the scrape_nucleus.py it will immediately open command promt and you default browser one the NucleusX web page fully open.
✅Login into you account.
✅Come back to cmd promt and press enter.
✅it will take few seconds and run & capture details of all booking uuid you have mentioned and save the session.
✅Then go to .ipynb file and run it in VS Code to get desire output in .xlxs file.
✅Remember the booking uuid will be same in both .ipynb & .py file.
